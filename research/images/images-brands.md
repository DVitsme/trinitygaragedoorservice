- No real Trinity job-site / portfolio photography appears on the brand pages; product images are generic representative shots, not Trinity's own installs.
- Brand logos in the footer strip are reused across all pages; some filenames are generic ("Image-12.png", "images-removebg-preview.png", "layer1.png") so the same file maps to different brands on different pages.
